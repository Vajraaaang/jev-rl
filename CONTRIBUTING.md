# Contributing

Keep changes tied to a verifiable engineering or scientific claim. Runtime is standard-library Python and native HTML/CSS/JavaScript. Before completion run full tests, compile, a tiny benchmark, audit and independent replay. HTTP tests need localhost binding permission. Browser-check real data, keyboard access and responsive layout for UI changes.

Use new experiment directories. Preserve failures and measured evidence. If simulator/reward/observation/model/rubric/splits change, record a new protocol and comparison. Do not tune from final test outcomes and still call the result confirmatory. Keep offline, mocked, cached hosted and fresh hosted evidence distinct.

New tools need explicit costs, durations, preconditions, observation outputs and independenthealth checks. Diagnostics accept collected public evidence only. Write causal, failure-path, split-leak and replay tests rather than implementation mirrors.

CI defines Python 3.10–3.13 install/test/smoke/audit/replay. Local tests do not prove hosted CI, Docker build, production transfer or Jev performance. Report states separately.
